# CarePoint Hospital Website

A responsive, multi-page hospital website starter built with HTML5, CSS3 and vanilla JavaScript only.

## Run locally
Open `index.html` in a browser, or run a local static server:
- VS Code: install/use Live Server and choose `index.html`.
- Python: `python -m http.server 8000`, then visit `http://localhost:8000`.

## Before publishing — mandatory customisation
1. Replace CarePoint Hospital with the real hospital name and logo.
2. Update all phone, email, address, working hours, emergency information and map embed.
3. Replace `https://www.example.com/` canonical URLs, Open Graph URL/image details and sitemap domain with the final HTTPS domain.
4. Replace doctor/team placeholder names, qualifications, photos and experience only with hospital-approved facts.
5. Verify all departments, facilities, emergency capabilities, accreditations and service claims.
6. Replace sample testimonials only with genuine feedback and documented permission.
7. Review privacy policy and terms with the hospital's responsible/legal team.
8. Confirm the WhatsApp destination `919850826021` is the intended hospital contact.
9. Add a real favicon, social preview image and optimised locally hosted images in `/images` if desired.

## WhatsApp and forms
Appointment and contact forms validate input in the browser and open WhatsApp with a prefilled message. The user must press Send in WhatsApp. This does **not** confirm an appointment and does not save data to a hospital database. Do not use this static form for sensitive medical information. For actual appointment management, integrate a secure backend, access controls, retention policy and appropriate privacy/security safeguards.

## SEO
Each page has its own title and description. Update canonical URLs, sitemap and robots.txt to the real domain. Add verified local business details and appropriate structured data only after the hospital identity, location and relevant facts are confirmed. This template intentionally does not fabricate physician or hospital credentials or promise Google rankings.

## Deploy to GitHub and Vercel
1. Create a GitHub repository and upload the complete `hospital-website` folder contents.
2. In Vercel, choose **Add New → Project**, import the repository.
3. Framework Preset: **Other**. Build Command: leave empty. Output Directory: `.`.
4. Deploy. Connect the hospital's domain in Vercel and configure the DNS records shown by Vercel.
5. Test all pages, links, WhatsApp forms, mobile layouts and SEO URLs on the live domain.

## Images
The template references public Unsplash image URLs for demonstration. For production, use hospital-owned/licensed imagery, download and optimise appropriately, provide descriptive alt text and avoid depicting a real doctor as an employee unless authorised.
